# simple-interest-calculator

## Project Description
A simple interest calculator that calculates the interest earned or paid on a principal amount over a specified period at a given rate of interest.

## Formula

Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Annual Rate of Interest
- T = Time (in years)

## Example

- Principal: ₹10,000
- Rate of Interest: 5%
- Time: 2 years

Calculation:

SI = (10000 × 5 × 2) / 100

**Simple Interest = ₹1,000**

**Total Amount = ₹11,000**

## Features
- Accepts principal amount, rate, and time.
- Calculates simple interest.
- Displays the total amount.
